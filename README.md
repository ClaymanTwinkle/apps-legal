# apps-legal

Privacy policies for Kesar's iOS apps, served by GitHub Pages at https://claymantwinkle.github.io/apps-legal/.

- PDScan: `pdscan/privacy-policy/index.html` → https://claymantwinkle.github.io/apps-legal/pdscan/privacy-policy/

Each app keeps the markdown source in its own repo (`docs/store/privacy-policy.md`); the HTML here is generated from it. Edit the markdown first, then regenerate.
